# 예배PPT 관리 시스템 — Vercel 정적 배포용

한국 교회용(새찬송가·개역개정) 예배 PPT 관리 시스템. 서버가 없습니다.
모든 데이터는 브라우저 `localStorage` + 내장 주보 샘플 데이터로 동작합니다.

## 파일 구성

- `index.html` — 화면 구조 (예배 관리 / 예배 중 송출 / 자료실 / 참고표 탭)
- `styles.css` — 차분한 디자인 (흰 종이 바탕, 짙은 남색 `#1e2a4a`, 금색 최소 사용)
- `app.js` — 편집·PPT 생성·송출·자료실 로직 (순수 JS)
- `data.js` — 주보 원문 샘플 데이터 4개 예배 + 참고표
- `vercel.json` — 정적 배포 설정 (`cleanUrls`)

외부 CDN은 PptxGenJS 하나만 씁니다.
`https://cdn.jsdelivr.net/npm/pptxgenjs@3.12.0/dist/pptxgen.bundle.js`

## 기능

1. **예배 관리** — 주일 낮 예배(추수감사절 10:30), 주일저녁 찬양예배(6:30), 삼일 기도회, 새벽 기도회 4개 예시. 왼쪽 목록 + 오른쪽 순서 상세 작업대. 날짜·절기·사회자·표어·순서 추가/삭제/수정, 찬송가 통/새 번호, 성경본문, 설교제목, 담당자 입력. 새 예배 만들기 가능. 변경은 `localStorage`에 저장.
2. **PPT 3종 내려받기** — PptxGenJS로 실제 `.pptx` 생성. ① 예배 순서 전체 ② 찬송가·찬양 ③ 말씀·교독문. 찬송가 가사는 저작권 때문에 비워두고 "가사는 찬송가 책을 확인해 주세요" 안내를 넣음. 성경 본문은 개역개정 초안임을 표시.
3. **예배 중 송출** — "찬송가 306" "신16" "진정한 감사절"처럼 검색하면 해당 슬라이드만 필터링. 클릭하면 검은 배경 큰 글씨 전체화면, 방향키/터치로 이동, ESC로 나가기.
4. **자료실** — 찬송가 가사·교독문 전문을 직접 등록하면 `localStorage`에 저장되고 순서·검색에서 재사용됨. 빈 상태면 "직접 등록해 주세요" 안내.
5. **참고표** — 봉사자·기도 담당자·구역 보고는 PPT에 포함하지 않고 참고용 표로만 표시 (주보 원문대로).

## 로컬에서 열기

빌드 도구가 필요 없습니다.

```bash
# 아무 정적 서버로 열기 (예시)
npx serve .
# 또는
python3 -m http.server 8000
```

`file://`로 직접 열어도 화면은 동작하지만, PPT 생성은 CDN(PptxGenJS)을 불러와야 하므로 인터넷 연결이 필요합니다.

## Vercel 배포

이 폴더를 그대로 Vercel 프로젝트로 연결하면 됩니다. GitHub에 올린 뒤 Vercel에서 Import → Framework는 "Other" (정적)로 두면 됩니다. 환경변수는 필요 없습니다.
